# 编码侧特征与 PSNR 预测扩展

日期：2026-10-09。保留原 60 次编码测量，新增数据和结果置于 prediction/；原视频及重编码文件不发布。

目标：实际采集最终第二遍编码的 QP 与帧内/帧间预测比例，检验在未见源视频上能否提高 PSNR-Y 预测精度，并更新现有公开 GitHub 仓库。

1. 使用原始输入、校准后的码率参数及最终第一遍率控文件重放第二遍编码，增加 x265 `csv-log-level=2`。逐段检查新 MP4 的 SHA-256 是否与原编码相同，不相同则禁止复用原 PSNR 标签。
2. CSV 的 QP 是最终帧平均 QP。按闭合 GOP 内 POC 重置恢复显示顺序，和原逐帧表按 sequence、target_kbps、frame 一一合并。CU 比例采用首组全帧 CU 计数百分比，区分帧类型占比与 CU 内预测模式占比。Skip/Merge 按实现合并为跳过类，并计入帧间预测。
3. 特征消融：码率/帧类型；SI/TI 基线；QP 单独对照；SI/TI+QP；再加 CU 帧内/帧间/跳过比例；最后加帧包 bits-per-pixel、源亮度统计。仅使用列白名单，禁止 PSNR、MSE、重建失真/能量、视频名称、文件哈希、另一档码率质量作为输入。
4. 同时预测逐帧 PSNR 与全视频 MSE 换算的序列 PSNR，二者分别建模；不把逐帧 dB 的平均当序列 PSNR。
5. 外层留一源视频交叉验证：同一视频所有帧及三个码率同时留出。Ridge 的 alpha 在训练视频内用三折 GroupKFold 选择，缩放/缺失值填充在每个训练折拟合。固定配置的直方图梯度提升回归作为非线性传统基线，不使用其随机内部 early stopping。所有消融共用外层划分。
6. 记录 RMSE、MAE、R²、每视频误差、每码率误差及逐样本 OOF 预测。主要消融比较采用同算法的 SI/TI 基线和 SI/TI+QP+CU；按整段源视频 bootstrap 成对 RMSE 差，明确 CV 折间训练重叠及 20 个源视频的小样本限制。扩展特征组单列，不以测试结果调参。
7. 生成实测/预测散点、消融误差、每视频误差改善图、中文报告、特征字典及完整复现命令。验证特征对齐、码流一致、无目标泄漏、训练/测试视频不重叠，再提交推送，检查公开远端字节。

主要模型：StandardScaler + Ridge，alpha 候选 0.1/1/10/100；备选非线性模型 HistGradientBoostingRegressor，学习率 0.06、150 次迭代、7 个叶子、L2=10，逐帧 min_samples_leaf=30，视频级=5。预先固定，不依据外层测试效果改变候选。

QP/CU/包大小是完成当前帧编码后可获得的特征，适用于编码侧质量估计，不构成编码前零代价质量预报。序列聚合需要完成该片段；当前 B 帧与 lookahead 配置也不是低延迟实时设置。采集耗时与预测推理耗时分别记录。
